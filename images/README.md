# Image Directory

This directory contains images for the website.

## Required Images

Please add the following images to this directory:

### 1. Favicon (`favicon.png`)
- Download from: https://github.com/user-attachments/assets/3a039120-e5a7-422b-9b79-c624792f31ec
- Size: 32x32 or 64x64 pixels
- Format: PNG

### 2. 404 Error Image (`404.png`)
- Download from: https://github.com/user-attachments/assets/c7f31993-ce6e-4c2f-8315-9777b47b592c
- Format: PNG

### 3. Bio Photo (`bio-photo.jpg`)
- Your professional headshot/profile picture
- Recommended size: 400x400 pixels or larger (square format)
- Supported formats: JPG, PNG, WebP

## Current Files

- `placeholder-profile.svg` - Fallback profile image (used when bio-photo.jpg is not available)

## Note

The website will gracefully fall back to placeholders if images are not present, but for the best appearance, please add all three images listed above.
